# C programming

What to teach, in which order, and when to test: `npm run syllabus` (see the rule in `dsa-syllabus.md`).

When teaching or checking C, always draw the three paper-and-pencil tracing templates in `brain/c-masterplan.md` (@brain/c-masterplan.md): the Address-Arrow Scaling Model for pointers and arrays, the Activation Stack + Static Store for recursion and statics, and the Variable State Table for loops.
